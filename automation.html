Автоматизация

Пишу ботов, парсеры и фоновые сервисы под рабочие задачи: контент, метрики, звонки, встречи. Репозитории не выкладываю. Ниже что делает каждый сервис и на чём он стоит.

Сервисы

  • TypeScript · BullMQ · Planka · LLM

    ContentOps Agent

    Берёт задачу из карточки Planka, строит план правок на сайте, показывает dry-run, пишет в базу и умеет откатить. Цены может считать с фото прайса.

  • Node.js · Метрика · Lark · PDF

    Analytics Agent

    В Lark кидаешь ссылку на объект. Бот тянет Яндекс Метрику и отвечает PDF с графиком.

  • TypeScript · Fastify · LLM · Kan

    SovaMeeting

    Из транскрипта встречи достаёт факты в wiki и черновики задач. В Kan уходит только после ручной проверки.

  • Go · DuckDB · S3 · PostgreSQL

    Контур аналитики

    События с сайтов уходят в S3, потом в DuckDB и витрины. Рядом реестр объектов и снимки для SEO и CRM.

  • Node.js · Playwright · S3 · NocoDB

    Map Parser

    По расписанию снимает организации и отзывы с карт. Если прогон упал, пишет в Telegram.

  • Node.js · Playwright · LLM · S3

    HH Parser

    Качает резюме, разбирает через LLM, складывает PDF/Markdown/JSON и шлёт в Telegram и Google Sheets.

  • Node.js · LLM

    Code Review Agent

    На вход diff и правила репозитория. На выход markdown с замечаниями по приоритету.

  • Node.js · Novofon · каталоги

    Аудит номеров

    Сводит виртуальные номера Novofon с телефонами на сайтах: куда уходит звонок и какие номера ни к чему не привязаны.

  • Node.js · PostgreSQL · Telegram · Lark

    Аудит размещений

    Кидаешь ссылку на объект в чат. Бот отвечает, что поменялось в статусах и услугах.

  • Node.js · Wiki.js · Lark · LLM

    Wiki-бот

    В Lark отвечает по Wiki.js и кидает ссылки на статьи. Скриншоты из чата тоже читает.

  • Node.js · Метрика · EspoCRM · NocoDB

    Синк метрик в CRM

    Раз в сутки забирает цифры из Яндекс Метрики и пишет их в карточки объектов в EspoCRM.

  • TypeScript · Playwright

    Мониторинг сайтов

    Смотрит доступность, SSL и скорость. В Telegram пишет, только если что-то отвалилось.
